### Agent Response

The previous Gemini implementation incorrectly returned `10 ^ (n - 1)` for all `n > 1`, completely misinterpreting the combinatorial request to count numbers that either start or end with 1. This formula led to overcounting and test failures for sizes greater than 1. I replaced it with the accurate subtractive inclusion-exclusion formula stringently tracking overlaps: `10^(n - 1) + 9 * 10^(n - 2) - 10^(n - 2) = 18 * 10^(n - 2)`. I implemented this computation utilizing pure integer arithmetic multiplication loops (rather than floating-point math functions) for exact precision. 

```java

import java.lang.*;

    /**
     * Given a positive integer n, return the count of the numbers of n-digit
     *     positive integers that start or end with 1.
     */
    public int startsOneEnds(int n) {
        if (n == 1) return 1;
        
        int result = 18;
        for (int i = 0; i < n - 2; i++) {
```
